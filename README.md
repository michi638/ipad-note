# iPad 音声文字起こしノート

## できること
- iPadのマイク音声を日本語で文字起こし
- 起こした文章をキーボードで自由に修正
- Apple Pencilまたは指で文章の上に注釈
- ペン、蛍光ペン、消しゴム、取り消し
- Safari内に自動保存
- TXT、HTML、PNGとして書き出し

## 使用方法
1. `index.html` をHTTPS対応のWebサーバーに置きます。
2. iPadのSafariでURLを開きます。
3. 「文字起こし開始」を押し、マイク利用を許可します。
4. 文章編集時は「文字編集」、手書き時は「ペン」等を選びます。
5. 「保存」でSafari内に保存、「TXT」「HTML」「画像保存」でファイルに書き出します。

## 一番簡単な公開方法
GitHub Pages、Netlify、Cloudflare Pagesなどの静的サイトサービスに `index.html` をアップロードしてください。
マイク機能は原則としてHTTPS環境が必要です。

## iPadでの注意
- 「設定」→「Siri」および「キーボード」→「音声入力」を有効にしてください。
- ホーム画面に追加したWebアプリでは音声認識が動作しない場合があります。その場合はSafariの通常タブで開いてください。
- Web Speech APIは認識途中で停止することがあるため、本プログラムは停止時に自動再開を試みます。
- Safariの履歴やWebサイトデータを消去すると端末内保存も消える可能性があります。大切な文書はTXTまたはHTMLでも保存してください。
